# Инструкции для агента

- Только вноси запрошенные изменения в файлы проекта.
- Не запускай тесты, сборку, линтеры, форматтеры, Plugin Verifier, IDE, CI-проверки и не отслеживай результаты CI. Проверка изменений — зона ответственности пользователя.
- Не создавай коммиты и не отправляй изменения на GitHub без отдельной явной команды пользователя.
- После внесения изменений кратко перечисли изменённые файлы и явно укажи, что проверки не запускались.
