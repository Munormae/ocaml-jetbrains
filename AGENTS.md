# Инструкции для агента

- Только вноси запрошенные изменения в файлы проекта.
- После изменения Kotlin-кода компилируй затронутый модуль. После изменения тестируемой логики запускай относящиеся к ней тесты.
- Перед созданием PR запускай `./gradlew check`. После изменения Platform API или plugin descriptor также запускай `./gradlew verifyPlugin`.
- После изменения Split Mode UI запускай `testIdeUiSplitMode`, если доступен `LICENSE_KEY`; при его отсутствии явно сообщай, что проверка не выполнялась.
- Не запускай IDE и не отслеживай результаты CI без отдельной просьбы пользователя.
- Не создавай коммиты и не отправляй изменения на GitHub без отдельной явной команды пользователя.
- После внесения изменений кратко перечисли изменённые файлы и результаты запущенных проверок; отдельно укажи проверки, которые не удалось запустить.
